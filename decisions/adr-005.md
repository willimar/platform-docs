Esse é um momento que merece ADR: "Resolução de conflito de nomes de pacote entre agentes". Contexto: múltiplos agentes no mesmo processo Python com diretórios tools/ conflitam via sys.modules. Decisão: registry limpa cache antes de cada load. Alternativa considerada: renomear diretórios (ex: youtube_tools/) — rejeitada porque quebra o contrato natural e exige rename por agente. Consequência aceita: o cleanup pode mascarar bugs de import circular, mas logs removendo_modulo_cacheado em DEBUG ajudam a auditar.
