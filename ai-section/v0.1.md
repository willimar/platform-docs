# Handoff — Agent Platform

## O projeto
Plataforma genérica de execução de agentes (YAML declarativo + loop
LLM + ferramentas @tool). Multi-repo no GitHub, dev local via uv workspace.

## Repos (github.com/willimar)
- agent-platform      → orquestrador: setup.ps1, push-all.ps1, LICENSE, README
- agent-sdk           → base: @tool, ToolResult, ToolSpec, ToolExecutionError
- platform-core       → motor: executor, registry, parser, loader, validator,
                        settings, logging, CLI `platform`
- google-calendar-agent → agente real (OAuth readonly, tool list_events)
- platform-docs       → docs, ADRs, guias

## Dev local (F:\ai-platform)
- pyproject raiz com [tool.uv.workspace] (members: os 3 pacotes)
- setup.ps1 clona irmãos e injeta nos consumidores:
  [tool.uv.sources] agent-sdk = { workspace = true }
- git update-index --assume-unchanged pyproject.toml
  (platform-core e google-calendar-agent)

## Convenções
- pyproject COMMITADO: dependency "agent-sdk" + UMA única seção
  [tool.uv.sources] agent-sdk = { git = "https://github.com/willimar/agent-sdk.git" }
- pyproject LOCAL: workspace=true, nunca commitar
- Licença: PolyForm Noncommercial 1.0.0 (código) / CC BY-NC 4.0 (docs)
- Ordem de push: agent-sdk → platform-core → google-calendar-agent
  → platform-docs → agent-platform
