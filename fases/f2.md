## Housekeeping rápido (2 min)

Vi nos seus `pyproject.toml` atuais que o `google-calendar-agent` ainda **não declara** o `agent-sdk`. Hoje funciona por sorte (o venv compartilhado do workspace contém o pacote), mas vai quebrar no dia que você publicar ou instalar isolado:

```toml
dependencies = [
    "google-api-python-client>=2.120",
    "google-auth>=2.30",
    "google-auth-oauthlib>=1.2",
    "google-auth-httplib2>=0.2",
    "agent-sdk",
]

[tool.uv.sources]
agent-sdk = { workspace = true }
```
